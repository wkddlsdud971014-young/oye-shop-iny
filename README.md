# 오예상점

작은 온라인 상점입니다. **상품 목록 · 상품 상세 · 장바구니 · 결제** 네 화면이 이어져 있습니다.

이 저장소를 내 계정으로 복제하고 배포하면 **그때부터 내 가게**입니다.

## 화면

| 파일 | 무엇 |
|---|---|
| `index.html` | 상품 목록 |
| `product.html` | 상품 상세 |
| `cart.html` | 장바구니 |
| `checkout.html` | 결제 |
| `done.html` | 주문 완료 |
| `about.html` | 가게 소개 |
| `shipping.html` | 배송·교환 안내 |

## 내 가게로 바꾸기

**`assets/shop.js` 하나만 고치면 됩니다.** 다른 파일은 건드리지 않아도 됩니다.

이 파일 안에 두 덩어리가 있습니다.

**`SHOP`** — 가게 정보

| 칸 | 무엇을 |
|---|---|
| `name` | 가게 이름. 화면 맨 위와 브라우저 탭에 나옵니다 |
| `tagline` | 한 줄 소개 |
| `about` | 가게 소개 문단들. 대괄호 안에 문장을 따옴표로 감싸 줄줄이 넣습니다 |
| `shipping` | 배송·교환 안내 문단들 |

**`PRODUCTS`** — 상품 여섯 개

| 칸 | 무엇을 |
|---|---|
| `id` | **바꾸지 마세요.** 주소에 쓰입니다 |
| `name` | 상품 이름 |
| `price` | 가격. 숫자만, 쉼표 없이 |
| `emoji` | 그림 대신 쓰는 문자 하나 |
| `summary` | 목록에 보이는 한 줄 |
| `detail` | 상세 화면 문단들. 여러 개 적을수록 좋습니다 |

> ⭐ **`about` 과 `detail` 을 짧게 쓰지 마세요.**
> 글이 적은 페이지는 검색에 잘 오르지 않습니다. 문단 서너 개는 채워 두세요.

## 이 저장소에 **없는** 것

일부러 넣지 않았습니다. 수업에서 직접 만듭니다.

- `sitemap.xml` — 검색엔진에 건네줄 주소 목록
- `robots.txt` — 무엇을 읽어도 되는지 적는 파일

## 건드리지 않아도 되는 것

| 파일 | 무엇 |
|---|---|
| `assets/app.js` | 화면을 그리고 장바구니를 다루는 코드 |
| `assets/style.css` | 겉모습 |

각 화면에는 **비워둔 자리**가 있습니다. 뒤 수업에서 여기를 채웁니다.

- HTML 파일 안 — 태그 관리자 코드가 들어갈 자리 (머리 / 몸통 맨 위)
- `assets/app.js` 안 — 「장바구니에 담았다」와 「결제를 시작했다」를 알리는 코드가 들어갈 자리

## 내 컴퓨터에서 열어보기

`index.html` 을 브라우저로 그냥 열면 됩니다. 서버가 없어도 돌아갑니다.

## 자주 막히는 자리

| 증상 | 이유 · 해결 |
|---|---|
| 고쳤는데 화면이 그대로다 | 브라우저가 예전 파일을 기억합니다. 새로고침을 세게 하세요 (`Ctrl`+`Shift`+`R`, 맥은 `Cmd`+`Shift`+`R`) |
| 상품이 하나도 안 보인다 | `assets/shop.js` 에서 쉼표나 따옴표가 빠졌을 수 있습니다. 브라우저에서 `F12` 를 눌러 빨간 글씨를 확인하세요 |
| 상세 화면에 "그런 상품이 없습니다" | `id` 를 바꿨을 때 생깁니다. 원래대로 돌려두세요 |
| 장바구니가 안 비워진다 | 브라우저에 저장된 값입니다. 결제를 끝까지 하면 비워집니다 |
